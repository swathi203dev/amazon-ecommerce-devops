# Amazon-Style E-Commerce DevOps Project

## Application
An e-commerce application with product listings, shopping cart,
checkout and order management.

## DevOps Technologies
- Linux
- Networking
- Git and GitHub
- Java
- Maven and Gradle
- Docker and Docker Compose
- Jenkins
- Kubernetes
- Terraform
- Prometheus and Grafana

## Project Goals
- Application development
- Automated builds and testing
- Containerization
- CI/CD automation
- Kubernetes deployment
- Scaling and reliability
- Infrastructure automation
- Monitoring

AWS is excluded. Render will be used for cloud hosting.
